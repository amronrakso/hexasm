# HEXASM

> **"Ce langage est un assembleur, directement lisible par un humain ou une machine, sans surcomplication. Et sans les fabricants de puces, ce projet n'a pas de sens..."**

## 📌 Présentation

**Hexasm** est un assembleur épuré et direct qui supprime les couches de complexité superflues. Se situant précisément à la frontière entre l'esprit humain et le silicium, il a été conçu pour être **immédiatement compréhensible à la lecture, tout en étant directement exécutable par une machine**. 

En encodant les concepts de bas niveau sans artifice, Hexasm offre une transparence totale sur les instructions. C'est un hommage à la relation directe entre le code et le matériel, car l'existence même de cet assembleur dépend de la réalité physique des puces électroniques fabriquées par les fondeurs.
